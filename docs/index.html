RuneScape: Dragonwilds · free & open source

Your own Dragonwilds server, with Discord built in, in one command.

An installer, a server mod and a Discord bot for Linux VPS and dedicated servers. Answer a few questions and get a running server with live leaderboards, two-way chat, a penguin hunt leaderboard, backups, updates and admin tools.

on your server
curl -fsSLO https://raw.githubusercontent.com/joaopmsilva/RSDWServerAPI/main/install.sh && sudo bash install.sh

Ubuntu 22.04+ or Debian 12+, 64-bit. About 15 minutes, most of it the game downloading.

Features

What you get

Everything runs on your server. Players join the way they always do.

A server in one command

  • Installs everything: packages, Node.js, steamcmd, the game, the mod and the bot
  • Hourly backups, newest 10 kept
  • Daily update and restart, with warnings in game and in Discord
  • Updates itself: a DM with an Update now button

For players, in Discord

  • /levels /quests /kills for anyone, live or last seen
  • Leaderboards: total level, any skill, quests, kills, penguins
  • /me, /gains, /playtime, /item
  • Raid and hunt alerts by DM, for those who want them

Live in your channels

  • Channels made for you when the bot joins
  • Two-way chat between the game and Discord
  • Deaths with the cause, level-ups, 99s and quests
  • Status board with how to join and who's on

For admins

  • /server: start, stop, restart, update, back up, restore
  • /admin: kick, ban, give items, announce
  • Private alerts for crashes, high CPU, RAM or disk
  • Carry-over checks for characters coming back from other worlds

Setup

Set up in four steps

No Linux experience needed. The full guide walks through every click.

Make a Discord bot

Create an application in the Discord Developer Portal, copy its token and turn on Message Content Intent.

2 minutes

Connect to your server

Open Terminal or PowerShell and ssh into the VPS your host gave you.

1 minute

Run the installer

Paste the command and answer the questions: your Player ID, server name, passwords and the bot token.

about 10 minutes

Invite the bot

Open the link it prints. The bot makes its channels and DMs you the admin commands. Then play.

1 minute
A Linux server: Ubuntu 22.04+ or Debian 12+, 2 GB RAM plus 1 GB per player, ~20 GB disk
A Discord server where you can add bots
Your Player ID from the bottom of the game's Settings

Penguin hunt leaderboard

Patch 1.0.2 let over 200 Killer Gentoo Penguins loose across Ashenfall. The bot ranks your hunters.

  • /leaderboard penguins: everyone ranked, with this week's haul
  • Fair: each penguin counts once per character
  • Catches up on penguins found before the mod loaded
